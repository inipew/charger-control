# 26 — Android Compatibility Matrix

## Tujuan
`production-grade` berarti tested compatibility, bukan sekadar compile success.

## Matrix
Catat minimal:

| Dimension | Example |
|---|---|
| Android | API level |
| Device | model/codename |
| SoC | Qualcomm/MediaTek/Exynos/etc. |
| Kernel | version/config |
| Charger driver | implementation/version |
| Battery nodes | available properties |
| Control nodes | path/value semantics |
| Vendor services | known external writers |
| SELinux | required allow/denial |
| Magisk | tested version/range |

## Status kategori
Gunakan tiga status:
- **Tested** — hardware nyata lulus test suite.
- **Compatible by capability** — belum diuji penuh tetapi profile/capability cocok.
- **Unsupported** — required capability tidak terpenuhi.

Jangan menyamakan “works on one Snapdragon device” dengan dukungan semua Snapdragon.

## Profile selection
Identity membantu memilih kandidat profile, tetapi final acceptance harus berdasarkan capability validation. Jika identity tidak dikenal namun generic capability cocok, behavior harus tetap konservatif.

## Acceptance criteria
1. Setiap release mencatat device matrix.
2. Profile baru memiliki fixture/test data.
3. Unsupported device tidak mengaktifkan write secara spekulatif.
4. Regression test mempertahankan behavior device yang sudah verified.
