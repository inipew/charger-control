# 02 — Architecture Invariants

Dokumen ini adalah registry aturan lintas komponen. Implementasi yang melanggar invariant dianggap bug walaupun test happy-path lulus.

## Layer contract

```text
Sensor/Kernel → Snapshot → Policy → Intent → Controller → HardwareIo
                         ↑                    ↓
                    Scheduler            Ownership
                         ↑                    ↓
                      Runtime ← IPC/Signal/Netlink
```

## Policy invariants
- **I-POL-001**: policy adalah pure decision berdasarkan snapshot/config/mode.
- **I-POL-002**: policy tidak melakukan I/O.
- **I-POL-003**: thermal cutoff obeys `thermal_cutoff`.
- **I-POL-004**: hysteresis mencegah oscillation.
- **I-POL-005**: unknown sensor tidak otomatis menjadi offline.

## Hardware invariants
- **I-HW-001**: semua write melewati controller.
- **I-HW-002**: write success bukan verification success.
- **I-HW-003**: partial write memicu reconciliation.
- **I-HW-004**: required dan optional node dibedakan.
- **I-HW-005**: unit/sign conversion dilakukan sebelum domain logic.

## Ownership invariants
- **I-OWN-001**: ownership persisted sebelum operation yang memerlukannya.
- **I-OWN-002**: release hanya committed setelah restore verified.
- **I-OWN-003**: crash tidak boleh menghapus evidence ownership.
- **I-OWN-004**: corrupt state tidak boleh dianggap valid.

## Runtime/IPC invariants
- **I-IPC-001**: IPC hanya mengirim command/event; tidak menulis hardware.
- **I-IPC-002**: privileged commands terotorisasi.
- **I-IPC-003**: shutdown menggunakan satu graceful path.
- **I-IPC-004**: parser dan request memiliki bounded resource.

## Temporal invariants
- **I-TIME-001**: deadline/age/backoff memakai monotonic time.
- **I-TIME-002**: event lama tidak mengalahkan state baru.
- **I-TIME-003**: operation memiliki identity yang dapat ditelusuri.

## Configuration invariants
- **I-CFG-001**: validation satu source of truth.
- **I-CFG-002**: invalid config tidak fallback silently.
- **I-CFG-003**: config write atomic.
- **I-CFG-004**: reload transactional.

## Scheduler invariants
- **I-SCH-001**: scheduler hanya menentukan waktu.
- **I-SCH-002**: netlink adalah accelerator.
- **I-SCH-003**: event storm dicoalesce.
- **I-SCH-004**: prediction tidak menjadi safety proof.

## Release invariant
- **I-REL-001**: production claim harus didukung test/evidence.

## Traceability
Setiap bug baru harus dicatat sebagai:

```text
BUG
 ↓
Invariant violated
 ↓
Required behavior
 ↓
Implementation
 ↓
Test proving invariant
```
