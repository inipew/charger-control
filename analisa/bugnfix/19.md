# 19 — Security Threat Model

## Threat surface
- local Unix socket;
- config/ownership files;
- CLI executable and arguments;
- sysfs paths and symlinks;
- log input from external events;
- untrusted local processes;
- malformed IPC requests;
- duplicate/flooded requests.

## Invariant
- **I-SEC-001**: privileged IPC must be least-privilege.
- **I-SEC-002**: daemon tidak menerima path hardware arbitrary dari untrusted client.
- **I-SEC-003**: request size, parsing, execution, dan timeout bounded.
- **I-SEC-004**: config/state directory permissions restrictive.
- **I-SEC-005**: secret/token tidak pernah masuk log.

## IPC
Socket default tidak boleh world-writable. Gunakan ownership/group yang tepat, mode restrictive, command allowlist, protocol version, request size limit, dan timeout. `shutdown`, `bypass`, atau mutation command harus memiliki authorization policy eksplisit.

## Filesystem
Config dan ownership harus disimpan pada directory yang hanya dapat dimodifikasi actor terpercaya. Pertimbangkan symlink-safe file opening dan validasi bahwa target tetap berada pada expected directory.

## TOCTOU
Jangan memvalidasi path kemudian membuka path tersebut dengan asumsi tidak berubah. Hardware paths sebaiknya berasal dari trusted profile yang sudah tervalidasi.

## Log injection
Nilai dari kernel/event/device profile harus structured field, bukan digabung sebagai format string mentah. Hindari karakter kontrol dan batasi panjang field.

## Acceptance criteria
1. Unprivileged local process tidak dapat mematikan atau mengubah policy tanpa authorization.
2. Fuzz parser IPC tidak panic.
3. Oversized request ditolak.
4. Arbitrary sysfs path dari client ditolak.
5. File state tidak dapat diubah melalui symlink attack dalam threat model yang didukung.
