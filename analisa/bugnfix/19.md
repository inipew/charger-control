# 19 — Security Threat Model

## Threat surface
```text
Unix socket
config files
ownership journal
sysfs paths
CLI arguments
log fields
malformed requests
request flooding
external local processes
```

Daemon berjalan dengan privilege tinggi, sehingga local IPC harus dianggap security boundary.

## Invariants
- **I-SEC-001**: privileged mutation least privilege.
- **I-SEC-002**: client tidak dapat memilih arbitrary hardware path.
- **I-SEC-003**: input/resource bounded.
- **I-SEC-004**: state/config directory restrictive.
- **I-SEC-005**: sensitive data tidak masuk log.

## IPC security
Gunakan:
```text
restrictive socket mode (contoh 0660)
trusted owner/group
command allowlist
authorization per command
protocol version
request size limit
read/write timeout
```

`status` dapat read-only; `bypass`, hardware mutation, dan shutdown membutuhkan privilege sesuai threat model.

## Filesystem
Config/ownership harus berada di directory trusted dengan permission restrictive. Hindari symlink/TOCTOU pada state files. Hardware paths hanya berasal dari trusted profile.

## Path injection
Client tidak boleh mengirim:
```text
/sys/... arbitrary path
```
untuk kemudian ditulis daemon root. API hanya menerima semantic command/capability identifier.

## DoS
Bound:
```text
request size
client count
queue size
parse cost
operation duration
log rate
```
Satu client tidak boleh memblokir daemon selamanya.

## Log safety
External strings menjadi structured fields dengan panjang bounded. Jangan memasukkan raw control characters atau secret ke log.

## Acceptance criteria
1. Unprivileged process tidak dapat mutation.
2. Fuzz parser tidak panic.
3. Oversized input ditolak.
4. Arbitrary sysfs path ditolak.
5. Symlink attack terhadap state file diuji sesuai permission model.
