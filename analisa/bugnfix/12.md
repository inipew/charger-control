# 12 — Implementation Roadmap & Definition of Done

## 1. Prinsip sequencing

Implementasi harus bergerak dari correctness menuju optimization. Jangan mengoptimalkan scheduler sebelum ownership/hardware transaction benar.

Dependency utama:

```text
Errors + Config
      ↓
Reader/Profile
      ↓
Policy
      ↓
Hardware Controller
      ↓
Ownership/Recovery
      ↓
Runtime/IPC
      ↓
Scheduler/Netlink
      ↓
Observability
      ↓
Real-device release
```

## 2. Phase 0 — Baseline evidence

Sebelum refactor:

```text
[ ] capture current tests
[ ] capture current device behaviour
[ ] enumerate charging nodes
[ ] enumerate writers/actors
[ ] record config schema
[ ] record lifecycle scripts
```

Tujuannya mencegah perubahan dianggap improvement padahal menghilangkan behaviour vendor yang dibutuhkan.

## 3. Phase 1 — P0 safety

Tutup:

```text
shutdown process::exit
thermal_cutoff guard
IPC direct hardware write
bypass direct write
IPC 0666/authorization
```

Exit gate: regression test untuk masing-masing P0.

## 4. Phase 2 — Hardware correctness

Implement:

```text
canonical HardwareIo
node capability model
semantic errors
partial-write reconciliation
checked integer conversion
control/electrical verification separation
```

Exit gate: seluruh mock hardware matrix pass.

## 5. Phase 3 — Ownership

Implement:

```text
operation ID
journal phases
atomic durable write
startup recovery
corruption handling
restore verification
```

Exit gate: crash injection pass pada seluruh checkpoints.

## 6. Phase 4 — Reader/profile

Satukan reader abstraction dan definisikan:

```text
source
unit
sign
required/optional
freshness
status mapping
capability
```

Exit gate: fixtures untuk minimal beberapa topology/vendor.

## 7. Phase 5 — Policy

Pastikan DecisionEngine pure dan lengkap:

```text
disabled
offline/unknown
charge limit/hysteresis
thermal enable/disable
fault/recovery
manual mode
```

Exit gate: deterministic matrix/property tests.

## 8. Phase 6 — Runtime/IPC

Satukan semua input sebagai event dan satu graceful shutdown path.

Exit gate:

```text
shutdown race
IPC security
bounded request
single writer
```

## 9. Phase 7 — Scheduler/netlink

Baru setelah correctness:

```text
debounce
reconnect backoff
adaptive intervals
EMA/ETA
wakeup budget
```

Exit gate: no-netlink correctness + power budget.

## 10. Phase 8 — Observability

Expose:

```text
policy state
hardware desired/applied/actual/verified
operation ID
ownership phase
last error
retry_at
sensor age
netlink state
```

Jangan expose sensitive paths/values jika tidak diperlukan.

## 11. Phase 9 — Android lifecycle

Test:

```text
boot
reboot
restart
crash
charger connected/disconnected
suspend/resume
Magisk update
Magisk disable
uninstall
rollback
```

## 12. Phase 10 — Release engineering

CI gate:

```text
fmt
clippy
unit
integration
property/fuzz
fault injection
cross target build
artifact checksum
```

## 13. Stop-ship conditions

Jangan release jika:

```text
[ ] direct write exists
[ ] shutdown can bypass controller
[ ] corrupt config silently becomes default
[ ] ownership crash recovery unknown
[ ] partial hardware failure unhandled
[ ] Fault can produce unsafe normal charging
[ ] IPC unauthenticated privileged mutation
[ ] supported device lacks evidence
```

## 14. Definition of Done

```text
[ ] all P0 closed
[ ] all critical invariants enforced
[ ] desired/applied/actual/verified separated
[ ] ownership durable
[ ] config transactional
[ ] reader canonical
[ ] policy deterministic
[ ] runtime serialized
[ ] scheduler bounded
[ ] compatibility matrix evidence-backed
[ ] release artifact reproducible/traceable
```

Production label berarti evidence tersedia untuk behaviour, bukan hanya repository berhasil compile.
