# 12 — Implementation Roadmap & Definition of Done

## Rule
Implement dari safety-critical menuju optimization. Jangan memulai dari scheduler/metrics sebelum ownership dan hardware boundary benar.

## Phase 1 — P0 safety
```text
shutdown ownership restore
thermal_cutoff guard
unify bypass through controller
IPC permission/authorization
config error handling
```

**Exit:** semua P0 memiliki regression test.

## Phase 2 — Hardware correctness
```text
profile capability
semantic hardware errors
partial-write reconciliation
checked conversions
verification model
reader unification
```

**Exit:** mock hardware matrix pass.

## Phase 3 — Ownership
```text
journal phases
operation IDs
crash recovery
corrupt-state handling
restore verification
```

**Exit:** fault injection pass.

## Phase 4 — Policy
Pure deterministic DecisionEngine untuk:
```text
presence
limit/hysteresis
thermal
fault
manual mode
```

## Phase 5 — Runtime
Single event loop; IPC/signal/netlink menjadi event producers. Satu graceful shutdown path.

## Phase 6 — Scheduler
Setelah correctness stabil:
```text
adaptive intervals
EMA
ETA
netlink acceleration
```

## Phase 7 — Observability
Status snapshot, structured logs, operation correlation, diagnostics.

## Phase 8 — Real-device validation
Boot, reboot, unplug/plug, suspend/resume, external writer, crash, update, rollback.

## Definition of Done
```text
[ ] all P0 closed
[ ] all critical invariants have tests
[ ] single hardware writer
[ ] desired/applied/actual/verified separated
[ ] ownership crash-safe
[ ] config atomic and validated
[ ] IPC secured
[ ] policy deterministic
[ ] netlink optional for correctness
[ ] scheduler bounded
[ ] compatibility matrix documented
[ ] release artifact traceable
```

Production label hanya boleh diberikan setelah evidence, bukan berdasarkan compile/test unit saja.
