# 16 — Multi-Actor & Ownership Arbitration

## Threat model
Charging state dapat diubah oleh:
```text
ChargerControl
Android framework
vendor HAL/daemon
thermal service
kernel driver
user/root CLI
Magisk module lain
```

## Invariant
Ownership adalah logical lease, bukan jaminan tidak ada actor lain yang bisa menulis sysfs.

## Arbitration
Saat managed:
```text
desired
 → apply
 → verify
 → monitor actual
```
Jika external actor mengubah state:
```text
detect mismatch
 → classify
 → bounded reconcile
```

Jika interference berulang:
```text
retry budget exhausted
 → degraded/fault
 → stop write fight
```

## Unmanaged
`Unmanaged` berarti tidak melakukan mutation. Observe-only behavior boleh dipertahankan untuk status/diagnostics.

## Safety hierarchy
Kernel/charger hardware thermal/current protections tetap authoritative. Userspace tidak boleh menganggap dirinya dapat meng-override hardware safety.

## Manual mode
Manual bypass harus memiliki explicit mode dan priority. Jangan biarkan policy normal diam-diam melawan manual command.

## Acceptance criteria
1. External writer dapat disimulasikan.
2. Bounded retry mencegah infinite loop.
3. Unmanaged tidak menulis.
4. Repeated interference menghasilkan diagnosable degraded state.
5. Safety actor tetap memiliki priority lebih tinggi.
